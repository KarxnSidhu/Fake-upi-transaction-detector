# App-specific reference screenshots

Add clean, permissioned reference screenshots to the matching directory:

- `google_pay/` — Google Pay screenshots
- `phonepe/` — PhonePe screenshots
- `paytm/` — Paytm screenshots

Supported formats: PNG, JPG, JPEG.

For a useful comparison set, collect several legitimate screenshots per app and
version, using different screen sizes where possible. Remove or safely redact
real names, UPI IDs, phone numbers, bank details and transaction references
before keeping any reference image. Do not use screenshots without permission.

A reference screenshot should keep the normal app layout intact. A changed app
version, font scaling setting or aspect ratio can reduce matching quality.

Until reference images are added, the API explicitly reports
`missing_reference`; it does not claim to have performed an app-layout check.
